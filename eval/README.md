# 평가 세트

실제로 품질 문제가 있었던 리뷰를 케이스로 모은다. 규칙을 고친 뒤 여기 있는 케이스를 다시 돌려, 고친 것이 다른 케이스를 깨지 않았는지 확인한다.

- `cases/NNN-이름.json` 한 파일에 케이스 하나.
- 필드: `review`(원문), `expected_type`(정답 유형), `must`/`must_not`(지켜야 할 점), `bad_output_before_fix`(문제가 된 결과), `good_example`(참고 답변).
- 채점 스크립트는 아직 없다. 생성은 아티팩트 안에서만 돌기 때문에, 지금은 사용자가 아티팩트에서 돌린 결과를 붙여 넣어 사람이 대조한다.
